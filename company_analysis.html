Data Source & Financial Reporting Standards

Financial statement figures (Revenue, Operating Cash Flow, Debt, Equity) are extracted from official corporate Investor Relations (IR) reports and regulatory SEC / BaFin filings (Forms 10-K, 10-Q, annual reports).

Python Implementation Architecture (Gerado Dinamicamente)

Pode executar esta lógica exata em Python utilizando yfinance e Telegram para automação 24/7 (ex: via GitHub Actions ou CronJob):

import yfinance as yf
import requests

TELEGRAM_BOT_TOKEN = "YOUR_BOT_TOKEN"
TELEGRAM_CHAT_ID = "YOUR_CHAT_ID"

def send_alert(msg):
    url = f"https://api.telegram.org/bot{TELEGRAM_BOT_TOKEN}/sendMessage"
    requests.post(url, json={"chat_id": TELEGRAM_CHAT_ID, "text": msg, "parse_mode": "Markdown"})

def check_objective_metrics(ticker_symbol, target_buy, target_sell):
    ticker = yf.Ticker(ticker_symbol)
    info = ticker.info
    price = info.get('currentPrice') or info.get('regularMarketPrice')
    
    if not price: return
    
    if price <= target_buy:
        send_alert(f"🟢 *BUY ALERT:* {ticker_symbol} price is {price:.2f} (Target Buy: {target_buy:.2f})")
    elif price >= target_sell:
        send_alert(f"🔴 *SELL ALERT:* {ticker_symbol} price is {price:.2f} (Target Sell: {target_sell:.2f})")

# Executar verificação para a sua Watchlist
watchlist = [
