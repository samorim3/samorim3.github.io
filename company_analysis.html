Como funcionam os Alertas? (How Alerts Work)

📱 1. Alertas 24/7 no Telegram (Recomendado)

Para ser alertado no telemóvel mesmo com o computador desligado, um bot em Python executa em plano de fundo de X em X horas. Quando a cotação atinge o seu preço alvo, o Telegram envia uma notificação push com a mensagem:

🟢 ALERTA DE COMPRA: Adidas (ADS.DE) caiu para €179.50 (Abaixo do seu alvo de €190.00)!

🌐 2. Alertas no Navegador (Web Page)

Sempre que pesquisar um Ticker ou abrir este projeto no seu navegador, as suas metas de preço ficam salvas (via localStorage) e o sistema calcula instantaneamente se o preço atual está em zona de COMPRA (Verde), VENDA (Vermelho) ou MANTER (Amarelo).

Código do Bot em Python (Telegram 24/7 Alerts)

Abaixo está o script pronto para executar no seu servidor ou computador para monitorizar a cotação e enviar alertas diretos para o seu Telegram:

import yfinance as yf
import requests

# 1. Configurações do seu Bot do Telegram
TELEGRAM_BOT_TOKEN = "SEU_BOT_TOKEN_AQUI"
TELEGRAM_CHAT_ID = "SEU_CHAT_ID_AQUI"

def send_telegram_alert(message):
    url = f"https://api.telegram.org/bot{TELEGRAM_BOT_TOKEN}/sendMessage"
    payload = {"chat_id": TELEGRAM_CHAT_ID, "text": message, "parse_mode": "Markdown"}
    requests.post(url, json=payload)

def check_stock_alerts(ticker_symbol, target_buy, target_sell):
    ticker = yf.Ticker(ticker_symbol)
    price = ticker.info.get('currentPrice') or ticker.info.get('regularMarketPrice')
    
    if not price:
        return
        
    print(f"Cotação Atual [{ticker_symbol}]: €{price:.2f}")
    
    if price <= target_buy:
        msg = f"🟢 *ALERTA DE COMPRA!*\n\nA empresa *{ticker_symbol}* caiu para *€{price:.2f}*, atingindo a sua meta mínima de compra (€{target_buy:.2f})."
        send_telegram_alert(msg)
    elif price >= target_sell:
        msg = f"🔴 *ALERTA DE VENDA!*\n\nA empresa *{ticker_symbol}* subiu para *€{price:.2f}*, atingindo a sua meta máxima de venda (€{target_sell:.2f})."
        send_telegram_alert(msg)

# Exemplo: Monitorizar a Adidas AG com Alerta de Compra em €190 e Venda em €240
check_stock_alerts("ADS.DE", target_buy=190.00, target_sell=240.00)
